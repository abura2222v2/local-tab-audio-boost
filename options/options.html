Saved pages

Exact page addresses are stored locally. Avoid adding URLs that contain passwords, access tokens, or other secrets.

Saving a page only stores its exact URL, a preferred volume, and an optional local name - it never starts boosting on its own, and no page is ever fetched. Use the popup's Enable boosting button (or its slider) on the page itself to actually start a session. To save a new page, open the popup on that page and use Add this page or Add URL manually.
