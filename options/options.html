Saved pages

Saved addresses and matching rules are stored locally. Avoid adding URLs that contain passwords, access tokens, or other secrets.

Saving a rule stores its address, matching scope, preferred volume, and optional local name. It does not immediately start boosting or fetch the page. When a matching address is opened later, the saved volume resumes automatically when the player supports fullscreen-compatible mode. You can also start or stop boosting from the popup.

Add an address

Export saved pages saves every saved page to a local JSON file. Import saved pages reads a local JSON file (this extension's own export, or a hand-edited list with the same shape) and adds its rules. An already-saved rule is overwritten with the imported values. Neither ever touches the network.
